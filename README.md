## 📌 About the Project

The **Food Order Dashboard** is an Excel-based data visualization
project that provides a quick overview of food-order activity. It brings
key performance indicators (KPIs), charts, and interactive slicers
together in one place to make the data easier to understand.

The dashboard helps users explore product-level performance, compare
order types, review state-wise order patterns, and examine agent
activity.

> 🎯 **Project goal:** Turn raw food-order data into a clear,
> interactive dashboard that supports quick analysis and
> decision-making.

------------------------------------------------------------------------

## ✨ Dashboard Features

-   🧮 **KPI Cards** --- a quick snapshot of important metrics.
-   🍕 **Product-wise Breakdown** --- a pie chart comparing the
    distribution across product names.
-   🗺️ **State-wise Order View** --- a line chart to compare order
    counts across states.
-   🛍️ **Order Type Comparison** --- a pie chart comparing **Online**
    and **Physical Visit** orders.
-   👥 **Agent Performance** --- a bar chart showing order counts by
    agent.
-   🎛️ **Interactive Slicers** --- filter the dashboard by product name,
    order type, agent, and state of order.
-   🎨 **Unified Design** --- a green colour palette, clear KPI cards,
    and a structured layout for readability.

## 📊 Key Performance Indicators (KPIs)

  -----------------------------------------------------------------------
  KPI                                 What it tells us
  ----------------------------------- -----------------------------------
  💰 **Total Sales**                  The sales value represented by the
                                      source data and its aggregation.

  📦 **Total Units Sold**             The total number of product units
                                      recorded.

  🍽️ **Unique Products**              The number of distinct products
                                      represented in the data.

  👥 **Total Agents**                 The number of agents represented in
                                      the data.

  🧾 **Average Price**                The average price value calculated
                                      from the dataset.
  -----------------------------------------------------------------------

**Important:** KPI values shown in a screenshot are a snapshot of the
current filter selection. They may change when the dashboard is
filtered. Confirm the source fields and aggregation methods before
interpreting a KPI as revenue, order count, or a distinct count.

## 🔎 Insights to Explore

Use the dashboard to investigate questions such as:

-   🍕 Which products make up the largest and smallest shares of the
    product chart?
-   🛍️ How does the distribution of **Online** orders compare with
    **Physical Visit** orders?
-   🗺️ Which states show higher or lower order counts?
-   👥 Which agents are associated with more orders in the current view?
-   🎛️ How do the charts and KPIs change when a product, agent, order
    type, or state is selected?

## 🖱️ How to Use

1.  Open the Excel workbook containing the dashboard.
2.  Review the KPI cards at the top for a quick summary.
3.  Use the slicers on the left and right to select a product, order
    type, agent, or state.
4.  Observe how the charts and any connected KPIs respond to the
    selection.
5.  Clear the filters to return to the broader view.
6.  Compare different selections to explore patterns in the data.
